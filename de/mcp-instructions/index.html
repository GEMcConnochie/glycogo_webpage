Deine Daten nutzen in Claude oder ChatGPT

Einrichtung für den Glycogo-Konnektor unter web.glycogo.fit

Adresse

RolleAdresse
Athlethttps://glycogo.fit/mcp/athlete
Trainerhttps://glycogo.fit/mcp/coach

Claude

  1. Anpassen → Konnektoren, dann Eigenen Konnektor hinzufügen.
  2. Adresse einfügen und Jetzt anmelden wählen. Das OAuth-Client-Feld bleibt leer.
  3. Zustimmungsseite bestätigen.
  4. Im Chat + → Konnektoren öffnen und einschalten.

Team und Enterprise: Ein Eigentümer fügt den Konnektor für alle hinzu, und jedes Mitglied meldet sich mit dem eigenen Konto an.

ChatGPT

  1. Plugins unter chatgpt.com/plugins, dann + und dann Benutzerdefinierten MCP-Server hinzufügen.
  2. Adresse einfügen, OAuth wählen und die Zustimmungsseite bestätigen.
  3. Installieren, dann im Chat @ eintippen und Glycogo auswählen.

Fehlt die Schaltfläche, dieselbe Adresse in der ChatGPT-Desktop-App unter Einstellungen → MCP-Server → Server hinzufügen.

Claude Code

claude mcp add --transport http glycogo https://glycogo.fit/mcp/athlete

Dann /mcp ausführen und anmelden.

Cursor

  1. Dies in ~/.cursor/mcp.jsoneintragen, oder in .cursor/mcp.json für ein einzelnes Projekt: 
    {"mcpServers":{"glycogo":{"url":"https://glycogo.fit/mcp/athlete"}}}
  2. Einschalten unter Anpassen → MCPs, dann im Browser anmelden.

VS Code

  1. Befehl MCP: Add Server in der Befehlspalette ausführen, HTTPwählen, die Adresse einfügen und dann Global → Copilot Global.
  2. Im Browser anmelden.

Für ein einzelnes Repository stattdessen dies in .mcp.json im Wurzelverzeichnis eintragen:

{"mcpServers":{"glycogo":{"type":"http","url":"https://glycogo.fit/mcp/athlete"}}}

Trennen

  • Entferne den Konnektor in Claude oder ChatGPT. Damit wird sein Token widerrufen.
  • Einstellungen → Überall abmelden in Glycogo beendet jeden Konnektor am Konto, und die App-Sitzung ebenfalls.
