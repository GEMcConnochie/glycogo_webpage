Configurazione del connettore Glycogo su web.glycogo.fit

Indirizzo

RuoloIndirizzo
Atletahttps://glycogo.fit/mcp/athlete
Allenatorehttps://glycogo.fit/mcp/coach

Claude

  1. Personalizza → Connettori, poi Aggiungi connettore personalizzato.
  2. Incolla il tuo indirizzo e scegli Accedi ora. Lascia invariato il campo client OAuth.
  3. Approva la pagina di consenso.
  4. In una conversazione, apri + → Connettori e attivalo.

Team ed Enterprise: un proprietario aggiunge il connettore per tutti, e ogni membro accede con il proprio account.

ChatGPT

  1. Plugin su chatgpt.com/plugins, poi + e poi Aggiungi server MCP personalizzato.
  2. Incolla il tuo indirizzo, scegli OAuth e approva la pagina di consenso.
  3. Installalo, poi digita @ in una chat e scegli Glycogo.

Se il pulsante manca, aggiungi lo stesso indirizzo nell'app desktop di ChatGPT sotto Impostazioni → Server MCP → Aggiungi server.

Claude Code

claude mcp add --transport http glycogo https://glycogo.fit/mcp/athlete

Poi esegui /mcp e accedi.

Cursor

  1. Aggiungi questo in ~/.cursor/mcp.json, oppure in .cursor/mcp.json per un singolo progetto: 
    {"mcpServers":{"glycogo":{"url":"https://glycogo.fit/mcp/athlete"}}}
  2. Attivalo in Personalizza → MCP, poi accedi quando si apre il browser.

VS Code

  1. Esegui MCP: Add Server dalla tavolozza dei comandi, scegli HTTP, incolla il tuo indirizzo e poi scegli Global → Copilot Global.
  2. Accedi quando si apre il browser.

Per un solo repository, metti questo in .mcp.json alla sua radice:

{"mcpServers":{"glycogo":{"type":"http","url":"https://glycogo.fit/mcp/athlete"}}}

Disconnetti

  • Rimuovi il connettore in Claude o ChatGPT. Questo revoca il suo token.
  • Impostazioni → Esci da tutte le sessioni in Glycogo chiude tutti i connettori dell'account, e anche la sessione dell'app.
