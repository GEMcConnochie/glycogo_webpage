Use your data in Claude or ChatGPT

Setup for the Glycogo connector at web.glycogo.fit

Address

RoleAddress
Athletehttps://glycogo.fit/mcp/athlete
Coachhttps://glycogo.fit/mcp/coach

Claude

  1. Customize → Connectors, then Add custom connector.
  2. Paste your address and choose Sign in now. Leave the OAuth client field alone.
  3. Approve the consent page.
  4. In a conversation, + → Connectors, and turn it on.

Team and Enterprise: an owner adds the connector for everyone, and each member signs in with their own account.

ChatGPT

  1. Plugins at chatgpt.com/plugins, then + and Add custom MCP server.
  2. Paste your address, choose OAuth, and approve the consent page.
  3. Install it, then type @ in a chat and pick Glycogo.

If the button is missing, add the same address in the ChatGPT desktop app under Settings → MCP servers → Add server.

Claude Code

claude mcp add --transport http glycogo https://glycogo.fit/mcp/athlete

Then run /mcp and sign in.

Cursor

  1. Add this to ~/.cursor/mcp.json, or to .cursor/mcp.json in a single project: 
    {"mcpServers":{"glycogo":{"url":"https://glycogo.fit/mcp/athlete"}}}
  2. Turn it on in Customize → MCPs, then sign in when the browser opens.

VS Code

  1. Run MCP: Add Server from the Command Palette, choose HTTP, paste your address, then choose Global → Copilot Global.
  2. Sign in when the browser opens.

For one repository instead, put this in .mcp.json at its root:

{"mcpServers":{"glycogo":{"type":"http","url":"https://glycogo.fit/mcp/athlete"}}}

Disconnect

  • Remove the connector in Claude or ChatGPT. That revokes its token.
  • Settings → Sign out everywhere in Glycogo ends every connector on the account, and the app session too.
