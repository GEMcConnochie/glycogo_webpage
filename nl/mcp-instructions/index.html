Instellingen voor de Glycogo-connector op web.glycogo.fit

Claude

  1. Aanpassen → Connectors, dan Aangepaste connector toevoegen.
  2. Plak je adres en kies Nu inloggen. Laat het OAuth-clientveld leeg.
  3. Keur de toestemmingspagina goed.
  4. Open in een gesprek + → Connectors en zet hem aan.

Team en Enterprise: een eigenaar voegt de connector voor iedereen toe, en elk lid logt in met het eigen account.

ChatGPT

  1. Plugins op chatgpt.com/plugins, dan + en dan Aangepaste MCP-server toevoegen.
  2. Plak je adres, kies OAuth en keur de toestemmingspagina goed.
  3. Installeer hem, typ dan @ in een chat en kies Glycogo.

Ontbreekt de knop, voeg dan hetzelfde adres toe in de ChatGPT-desktopapp onder Instellingen → MCP-servers → Server toevoegen.

Claude Code

claude mcp add --transport http glycogo https://glycogo.fit/mcp/athlete

Voer dan /mcp uit en log in.

Cursor

  1. Zet dit in ~/.cursor/mcp.json, of in .cursor/mcp.json voor één project: 
    {"mcpServers":{"glycogo":{"url":"https://glycogo.fit/mcp/athlete"}}}
  2. Zet hem aan in Aanpassen → MCP's, en log in wanneer de browser opent.

VS Code

  1. Voer MCP: Add Server uit via de Command Palette, kies HTTP, plak je adres en kies dan Global → Copilot Global.
  2. Log in wanneer de browser opent.

Voor één repository zet je dit in .mcp.json in de root:

{"mcpServers":{"glycogo":{"type":"http","url":"https://glycogo.fit/mcp/athlete"}}}

Loskoppelen

  • Verwijder de connector in Claude of ChatGPT. Daarmee wordt het token ingetrokken.
  • Instellingen → Overal uitloggen in Glycogo beëindigt elke connector op het account, en ook de appsessie.
